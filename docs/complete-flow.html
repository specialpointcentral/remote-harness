remote-harness remote-only flow

所有 Claude、Codex、opencode 和 subagent 都运行在远端服务器。本机只提供项目文件和项目命令环境。

remote Agent tools -> SSHFS -> local project files
remote Bash -> Claude/Codex hook or opencode plugin -> rh-run -> forced SSH gateway -> local project command
remote Agent/Spawn -> remote subagent

forced gateway 只接受 SFTP、remote-harness-health 和 remote-harness-exec。forward 本机 Agent 模式已禁用。

SFTP 是账号级访问，不是项目 chroot；绝对隔离需要独立、受限的本机 OS 账号。
